# Class Attendance List

A clean, responsive class attendance tracking application built with pure vanilla HTML, CSS, and JavaScript. All data is persisted locally in the browser using `localStorage`.

## 🚀 Features

- **Add Attendance**: Record student name, date (defaults to today), and status (**Present** or **Absent**).
- **Attendance Records List**: Neat, structured list of all student attendance records sorted by date descending.
- **Edit Records**: Update student names, dates, or attendance statuses at any time.
- **Delete with Confirmation**: Safeguard against accidental deletions with confirmation dialogs.
- **Instant Search & Filter**: Search records in real-time by student name or date, with filter tabs for *All*, *Present*, and *Absent*.
- **Top Stats Summary**: Overview cards showing Total Records, Total Present, and Total Absent.
- **Empty States**: Friendly messaging when starting fresh or when search returns no matches.
- **Mobile Responsive**: Touch-friendly design optimized for smartphones, tablets, and desktops.
- **Client-Side Persistence**: Fully offline-capable, saving all changes to browser `localStorage` without a backend or server.

## 🛠️ Tech Stack

- **HTML5**: Semantic and accessible markup
- **CSS3**: Mobile-first responsive styling with clean UI components
- **JavaScript (ES6+)**: Pure vanilla JS for state management and DOM updates

## 💻 Getting Started

Simply open `index.html` in any modern web browser. No installation, build step, or server required!
